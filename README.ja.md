## 機能
- 日付、時間、位置に基づいて太陽の位置を視覚化する
- 窓のある3Dルームの室内照明をシミュレーションする
- 1日分を自動的に再生する

## 要件
このプロジェクトは Three.js と CSV ライブラリを使用しており、それらはインポートマップを介してインポートされます。

## 使用方法
1. リポジトリをクローンしてください。
2. `index.html` ファイルをウェブブラウザで開いてください。

## データ / API
このプロジェクトは外部のデータやAPIを使用していません。
